## 如何运行测试

1. 启动开发服务器:
```bash
npm run dev
```

2. 访问 http://localhost:3000

3. 登录/注册账号

4. 进入"JD分析"页面

5. 粘贴上述测试用例中的JD内容

6. 点击"开始分析"

7. 对比分析结果与预期输出

## 注意事项

- 当前版本使用本地算法，准确度约80%
- 后续版本将集成OpenAI API提升准确度
- ATS关键词提取依赖于文本中的特定词汇
- 技能识别基于预定义的模式库，可能遗漏部分技能
- 匹配度计算基于规则算法，结果仅供参考
